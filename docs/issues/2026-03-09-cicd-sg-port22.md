# CI/CD 배포 실패 - EC2 보안그룹 22번 포트 차단

## 개요

- **발생일**: 2026-03-09
- **영향 범위**: main 브랜치 push 시 자동 배포 전체 실패
- **심각도**: 배포 불가

---

## 증상

GitHub Actions Run #12에서 배포 파이프라인 실패.

```
drone-scp error: error copy file to dest: ***, error message: dial tcp ***:22: i/o timeout
Error: Process completed with exit code 1.
```

**실패 스텝**: `Copy Docker Compose file to EC2`
**이후 스텝**: `EC2 배포 수행` skipped

---

## 원인

EC2 보안그룹 인바운드 규칙에 22번 포트(SSH)가 허용되어 있지 않아 GitHub Actions 러너가 EC2에 접근하지 못함.

---

## 해결 방법

배포 중에만 동적으로 22번 포트를 열고 닫는 방식으로 변경.

### 변경된 워크플로우 흐름

```
빌드 → ECR 푸시 → [보안그룹 22번 열기] → SCP → SSH 배포 → [보안그룹 22번 닫기]
```

- 배포 시작 전: GitHub Actions 러너 IP만 22번 포트 허용
- 배포 완료 후: 해당 규칙 즉시 제거 (`if: always()`로 실패해도 반드시 닫힘)

### 추가된 AWS IAM 권한 (`GitHubActions-Deploy-Role`)

```json
{
  "Effect": "Allow",
  "Action": [
    "ec2:AuthorizeSecurityGroupIngress",
    "ec2:RevokeSecurityGroupIngress"
  ],
  "Resource": "*"
}
```

### 추가된 GitHub Secret

| 키 | 값 |
|----|-----|
| `EC2_SG_ID` | EC2 보안그룹 ID (`sg-xxxxxxxxx`) |
